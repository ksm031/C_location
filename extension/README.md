# 진열로케이션정리 빠른 등록 (크롬 확장)

인트라넷 탭에서 단축키 한 번으로 페이지 내용을 긁어, 옆에 뜬 사이드바의
앱으로 바로 넘겨 등록합니다. 탭을 옮기거나 Ctrl+A → Ctrl+C 할 필요가 없습니다.

## 설치 (개발자 모드)

1. 크롬 주소창에 `chrome://extensions` 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** 클릭 → 이 `extension` 폴더 선택

## 사용법

1. 인트라넷의 **진열작업 오류보고 상세** 또는 **입고 토트 상세** 페이지를 연다
2. **Ctrl+Shift+Y** (맥: Cmd+Shift+Y)
3. 오른쪽에 사이드바가 열리고, 페이지 내용이 이미 파싱된 상태로 뜬다
4. 확인하고 저장

단축키를 바꾸려면 `chrome://extensions/shortcuts` 에서 변경하면 됩니다.
툴바의 확장 아이콘을 눌러도 사이드바가 열립니다.

## 처음 한 번만

사이드바 안의 앱은 별도 세션으로 취급되어 **로그인을 한 번 더** 해야 합니다.
이후에는 유지됩니다.

## 동작 방식

```
단축키 → background.js
          ├ 사이드바 열기 (chrome.sidePanel)
          ├ 현재 탭에서 document.body.innerText 수집
          └ storage + 메시지로 사이드바에 전달
                        ↓
        sidepanel.js → iframe(앱) 으로 postMessage
                        ↓
        앱이 붙여넣기 모달을 열고 자동 파싱 → 사용자가 확인 후 저장
```

표 셀이 탭 문자로 구분되는 `innerText` 를 쓰기 때문에, 손으로
Ctrl+A → Ctrl+C 한 것과 같은 형태가 되어 기존 파서가 그대로 읽습니다.

## 요구 사항 / 제한

- 크롬 **114 이상** (Side Panel API)
- 사이드바가 비어 있고 안내문이 뜨면, 앱 사이트가 iframe 삽입을 거부하는
  경우입니다. 그때는 안내의 **긁어온 내용 복사** 버튼을 쓰거나,
  `sidepanel.html` 의 iframe 대신 빌드된 앱(`dist/`)을 확장에 포함시키는
  방식으로 바꾸면 됩니다.
- 저장은 항상 사용자가 확인해야 진행됩니다 (자동 저장 아님).
